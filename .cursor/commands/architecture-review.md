# Architecture Review

System under review: @[file or folder]

## Required questions

1. Which NuGet package is impacted?
2. Would this be designed this way from scratch today?
3. Controls/Theme split violation?
4. Unnecessary abstraction vs native Avalonia?
5. Impact on NuGet consumers?

## Response format

- **Good** — what works
- **Problems** — issues found
- **Recommendation** — keep | simplify | redesign | remove
- **Trade-offs** — cost vs benefit
